## Evidence boundary for dissertation reporting

- **Can be reported as technical/project evidence:** implemented artifact behavior, saved test runs, source checks within recorded scope, scenario comparisons, runtime observations, mock browser states and synthetic report calculations.
- **Must be reported as prepared only:** adult-user instruments, independent relevance rating packs, proposed task comparison, consent/data plan and thematic-analysis template.
- **Must not be reported as findings:** participant usability, trust, comprehension, satisfaction, independently judged relevance, nDCG, learning outcomes, educational effectiveness or accessibility improvement.
- **Non-negotiable data statement:** zero genuine participant responses. Synthetic records remain demonstration/test data and must be labelled accordingly.
