- Six of the seven sources appear in the central bibliography with traceable DOI or publication URLs. The Burke entry is missing issue number 4, an optional completeness improvement.

- The old 29 October registers are historical records and should not be silently overwritten as if the full text had been seen then. The Stage 2A CSV is an additive, dated verification record. It supersedes only current access-status decisions for these seven sources.
