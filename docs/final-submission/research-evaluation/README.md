# Evaluation review pack

Start with ETHICS_REVIEW_COVER.md and verify signed approval before using any instrument. PARTICIPANT_INFORMATION_AND_CONSENT.md contains the proposed participant wording and custom questionnaire. TASKS_AND_EXPLANATION_RUBRIC.md supplies tasks and objective probes. ANALYSIS_PLAN_AND_RESULTS_PLACEHOLDER.md specifies analysis and visibly empty results. RELEVANCE_PROTOCOL.md separates independent ranking judgements from usability. The CSV templates are header-only; manual checks remain PENDING.

This package is review-ready working material, not an ethics approval or a claim that completed university forms are available. Do not place completed personal/participant data in this repository.
