## Interpretations that remain defensible only with limits

SBERT/MiniLM papers justify exploring representations, not educational recommendation accuracy. Burke supports hybrid framing, not this prototype's superiority. The education reviews concern learning/recommendation contexts with limited transfer to admissions. The historical NEC report does not establish current target-group needs. Tintarev/Masthoff supports distinguishing explanation goals; it does not prove this UI improves trust. The nDCG source motivates graded evaluation but cannot supply missing relevance judgements. WCAG describes criteria; an axe report is not complete conformance.
