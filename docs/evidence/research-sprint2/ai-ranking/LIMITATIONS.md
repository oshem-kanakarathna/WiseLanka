# Interpretation limits

- Nine cases were used during development. Twelve new cases were frozen prospectively by a catalogue-aware evaluator, not an independent designer. No genuinely independent held-out scenario set is available; no tuning occurred in this sprint.
- No independent labels or participant observations exist. Changed order, paraphrase stability or a positive cosine is not recommendation accuracy, trust, usability or educational benefit. Empty/noise queries are robustness cases, not legitimate preference-quality targets.
- The catalogue has11 programmes (IT7,Business1,Engineering3), with only short identity/subject/type text. Candidate generation can restrict A/L queries to5 programmes and O/L to a singleton. A ranker cannot retrieve an excluded candidate; larger text/model changes would be a different experiment.
- Most candidates areNOT_ASSESSED because formal selection/provider evidence is unresolved. Policy groups remain protected, but can place aMET foundation before a more interest-related unknown degree. No admission probability or selected-place decision is inferred.
- Custom TF–IDF uses raw counts/smoothedIDF without stopword removal/stemming; common words influence short titles. It is a reproducible simple comparator, not an optimised representative of every lexical technique. Deterministic mode also computes lexical diagnostics in the production rank function.
- English-only semantic support remains the documented scope. No multilingual, voice, cross-cultural relevance or fairness benefit was tested. No performance improvement from feedback learning is claimed; model inference is frozen and TF–IDF does not learn learner preferences.
- Repeated timings are correlated observations on one shared AppleM4/macOS host. Cold workers are fresh processes with potentially warmOS file caches, not cold-machine deployment. Rank-only timings exclude academic processing/UI/network. Worker high-waterRSS is not exact model allocation or full-service memory.
- Warm samples compare scenario-specific candidate pools, while cold measurements use onlyF01. Shared code performs catalogue/lexical work even in deterministic mode; comparing these timings as isolated algorithm complexities would be misleading.
- Missing-model behaviour was deliberately induced only in an isolated process. It confirms fallback logic, not real availability rates. No cache/weight corruption, download outage, production load or concurrency experiment was performed.
- Source-grounded eligibility remains the existing prototype's assessment, not independently re-adjudicated in this ranking sprint. Sprint2A input/provenance/coverage limitations remain; this experiment does not repair them.
- Blinded packs are prepared but not released for recruitment. Ethics applicability, judge independence/competence, disagreement analysis and source-access rules must be confirmed before use. Existing cases do not become held-out after independent rating.

No application/model/dataset changes, training, participant data, fabricated labels, dissertation rewrite or remote push. PartA alone created the authorised local correction checkpoint; PartB outputs remain uncommitted for review.
