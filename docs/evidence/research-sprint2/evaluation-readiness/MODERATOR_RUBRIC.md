# Researcher-only task and comprehension anchors

Withhold this file from participants during tasks. Anchors describe represented rules and limitations, not externally adjudicated admissions. Inputs are copied from the preserved WP5 synthetic set; no new technical run or source verification is claimed. Before collection dry-run the frozen UI and spot-check official sources; unexpected changes must be logged and resolved, not taught as known truth.

Completion: UNASSISTED if the stated observable goal is reached without help; ASSISTED if reached after help; NOT_COMPLETED if attempted but not reached; SKIPPED, TECHNICAL_FAILURE and WITHDRAWN separately. Never turn unanswered into a failed comprehension answer.

Neutral comprehension probes (record response before scoring):

| ID | Question | 0 / 1 / 2 anchors |
|---|---|---|
| C1 | What does this NOT_ASSESSED result mean? | 0 confirmed rejection/admission; 1 vague uncertainty; 2 missing evidence/decision and neither confirmation nor rejection |
| C2 | What does this relevance information tell you, and what does it not tell you? | 0 admission/competence probability; 1 content fit only without contrast; 2 stated-interest/content relationship distinct from eligibility/admission |
| C3 | What does the Engineering result show, and what could be checked next? | 0 unsupported acceptance or learner-ability judgement; 1 identifies some academic gap; 2 identifies Physics gap and a cautious source/provider or alternative-route next step |
| C4 | What must happen before the vocational progression can be confirmed? | 0 automatic entry/equivalence; 1 one partial condition; 2 qualification/document plus provider/selection uncertainty, no guarantee |
| C5 | What can we conclude about a skill that this learner did not report? | 0 assumes inability; 1 recognises uncertainty; 2 not reported is not verified lack/competence; self-report only |

N/A/not asked, skipped and unintelligible/unanswered are separate missing states, not score 0. For a different displayed programme record it and use its actual assessment; do not score against the wrong card. Two independent scorers are desirable if ethically approved; lock initial scores before discussing disagreement. Otherwise disclose author scoring and its bias. This custom rubric is not a validated test or evidence of a learning gain.
